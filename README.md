# CoreERP - Enterprise Inventory Management (Module 01 Frontend)

A responsive, accessible enterprise management UI built with semantic HTML5 and a tokenized CSS architecture. Designed as the frontend foundation for a full-stack ERP system with RESTful integration.

## Architecture Highlights
- **Design Tokens:** Strict CSS variable-driven palette adhering to high contrast and dark mode tokens.
- **Accessibility:** Semantic HTML elements (`aside`, `main`, `table`, `header`, `section`) with comprehensive ARIA tags.
- **Responsive Layout:** Flexbox shell with a dynamic CSS Grid KPI dashboard that automatically scales across viewport breakpoints.
- **Module Mapping:** Pre-structured data fields (`SKU`, `Warehouse Bin`, `Available Qty`, `Reorder Point`) built to map directly to relational SQL schemas in subsequent modules.
